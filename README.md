# Yojana Mitra – योजना मित्र

**Yojana Mitra** is an independent citizen-assistance prototype developed by **Team SegFault Survivors** for **YCCE HackKumbh 2026**.

It helps citizens discover Maharashtra and Central Government schemes, check eligibility, prepare required documents, and proceed to official application portals.

> **Disclaimer:** Yojana Mitra is not a government website. It is an independent prototype. All applications must be submitted through the respective official government portals.

## ✨ Key Features

- **Multilingual Interface:** Supports Marathi, Hindi, and English.
- **Accessibility:** Large-text mode (A+) for improved readability.
- **Smart Eligibility Checker:** Rule-based eligibility checking for 10 government schemes, with clear explanations.
- **Personalized Document Checklist:** Displays required documents based on eligible schemes.
- **Application Tracker:** Helps users track their application progress.
- **Help Center:** Includes an error troubleshooter and grievance letter generator.
- **Document Formatter:** Format documents directly on your device.
- **PDF Tools:** Create and compress PDFs.
- **Image Slideshow:** Visual information and scheme awareness.
- **Voice Support:** Voice input and read-aloud functionality.

## 🚀 How to Run the Project

The project is a standalone HTML application. No installation is required.

### Steps:

1. Download or clone this repository.
2. Locate the `yoj3.html` file.
3. Double-click `yoj3.html` to open it in your browser.
4. Alternatively, right-click the file and select Open With → Chrome, Edge, or Firefox.
5. Connect to the internet once to allow external fonts and PDF tools to load.
6. Use the language buttons to switch between Marathi, Hindi, and English.

### Run Using VS Code (Optional)

1. Open the repository folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `yoj3.html`.
4. Select **Open with Live Server**.
5. The project will open in your default browser.

## 🔒 Privacy & Data Security

- User data stays on the user's device.
- Aadhaar numbers are never stored.
- The prototype is designed to provide assistance without replacing official government services.
