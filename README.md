# Yojana Mitra – योजना मित्र

Yojana Mitra is an independent citizen-assistance prototype built by Team SegFault Survivors for YCCE HackKumbh 2026. It helps people find Maharashtra and central government schemes, check eligibility, prepare documents and continue on the official portal. It is not a government website, and applications are always submitted on the official portal.

## Key features
- Marathi, Hindi and English interface, plus a large-text mode (A+)
- Profile form with rule-based eligibility for 10 schemes, with clear reasons for every result
- Personalised document checklists and an application tracker
- Help Center with an error troubleshooter and grievance letter writer
- Document Formatter, PDF creator and PDF compressor that run on your device
- Image slideshow, voice input and read-aloud support

## How to run the HTML code
The whole project is one file: `yojana-mitra-with-slideshow.html`. No installation is needed.

1. Download the file to your computer.
2. Double-click it, or right-click and choose Open with → Chrome, Edge or Firefox.
3. The site opens in your browser. Use the buttons at the top to change language.

**To edit the code:** open the file in VS Code or Notepad, make changes, save, then refresh the browser (F5) to see them.

**Optional live preview:** in VS Code, install the Live Server extension, right-click the file and choose Open with Live Server.

## Notes
- Connect to the internet once so fonts and PDF tools can load.
- Your data stays on your device, and Aadhaar numbers are never stored.
- Scheme rules are demo data, so always verify on the official portals.
